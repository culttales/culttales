================================================================================
CULT. TALES — QUICK START GUIDE
================================================================================

WHAT YOU HAVE:
A production-ready Next.js website for your Pan Indian wedding storytelling
brand. Complete with 6 sample stories, films, articles, and a full design system.

STATUS: Ready to extract, customize, and deploy.

================================================================================
1. EXTRACT & INSTALL (2 minutes)
================================================================================

  unzip cult-tales.zip
  cd cult-tales
  npm install

================================================================================
2. RUN LOCALLY (30 seconds)
================================================================================

  npm run dev

Then open http://localhost:3000 in your browser.

You'll see the complete site with sample stories, films, and articles.

================================================================================
3. CUSTOMIZE YOUR CONTENT (30 minutes)
================================================================================

Before going live, replace:

  A. Stories
     → Open: lib/stories.ts
     → Replace the 6 sample weddings with yours
     → Add more entries following the same structure
     → URL automatically becomes: /stories/[slug]

  B. Films
     → Open: lib/films.ts
     → Replace 4 sample films with your actual films
     → Wire video URLs into VideoPlayer component

  C. Journal Articles
     → Open: lib/journal.ts
     → Replace 4 sample articles with your content
     → Articles auto-populate the journal section

  D. Contact Info
     → Edit: app/contact/page.tsx (email, phone, socials)
     → Edit: components/Footer.tsx (contact links)
     → Update domain in: app/layout.tsx

  E. Images
     → Replace placeholder images in: public/images/
     → Update image paths in lib/stories.ts

================================================================================
4. BUILD FOR PRODUCTION (1 minute)
================================================================================

  npm run build

This creates an optimized production build.

================================================================================
5. DEPLOY (2 minutes)
================================================================================

OPTION A: Vercel (Recommended)
  • Push code to GitHub
  • Go to vercel.com
  • Import your repository
  • Deploy (automatic on every push)

OPTION B: Traditional Server
  npm start

OPTION C: Static Export
  • Enable in next.config.mjs
  • Deploy to any CDN (Cloudflare, Netlify, etc.)

================================================================================
ADDING A WEDDING STORY
================================================================================

1. Open: lib/stories.ts

2. Add to the `stories` array:

   {
     slug: "couple-name-city-wedding",
     title: "Couple Names",
     coupleNames: "Name & Name",
     location: "City, Region",
     region: "Region Name",
     year: "2026",
     category: "Wedding Story",
     heroImage: "/images/hero.jpg",
     cardImage: "/images/card.jpg",
     excerpt: "One sentence summary of the wedding",
     openingLine: "Evocative opening: 'Where X meets Y...'",
     description: "Full story (2–3 sentences about the wedding)",
     images: [
       { src: "/images/img1.jpg", alt: "Description", orientation: "portrait" },
       { src: "/images/img2.jpg", alt: "Description", orientation: "landscape" },
       { src: "/images/img3.jpg", alt: "Description", orientation: "portrait" },
     ],
     film: "/images/film-poster.jpg",  // Optional
     rituals: [
       { name: "Ritual Name", description: "What this ritual means..." },
       { name: "Another Ritual", description: "..." },
     ],
     featured: true,  // Optional: shows on homepage
   }

3. URL automatically becomes: /stories/couple-name-city-wedding

4. Save and refresh the browser — your story is live.

================================================================================
TROUBLESHOOTING
================================================================================

Q: Images aren't showing
A: Check paths in lib/stories.ts match files in public/images/

Q: Styles look broken
A: Restart dev server: npm run dev

Q: Fonts not loading
A: They're self-hosted via next/font. Rebuild: npm run build

Q: Animations not working
A: Check prefers-reduced-motion isn't enabled in OS settings

See full README.md for more help.
