================================================================================
CULT. TALES — QUICK START GUIDE
================================================================================

The CULT. tales website: Next.js 16, hosted on Cloudflare Workers.
Short for Culture. Long on Tales.

================================================================================
1. RUN IT ON YOUR COMPUTER
================================================================================

  npm install
  npm run dev

Then open http://localhost:3000 in your browser. Pages update as you save.

To check the production build instead:

  npm run build
  npm start

================================================================================
2. EDIT THE CONTENT
================================================================================

  A. Wedding stories → lib/stories.ts
     The six stories are PLACEHOLDERS: the names, places and texts are
     stand-ins, shown with real photographs that are not of those couples.
     Replace each one with a real wedding. Each story needs a `zone`
     ("north", "south" or "east-west") for the homepage filters.
     Use `cardFocus` (e.g. "68% 40%") to keep faces in frame when a photo
     is cropped. Add `film` and `filmSrc` only when the story has footage.

  B. Films → lib/films.ts
     Only films with a `src` appear on the site. Titles and places of the
     two real films are still placeholders. Keep each video file under
     25 MiB (Cloudflare's limit), or serve it from R2 (docs/CLOUDFLARE.md).

  C. Journal → lib/journal.ts

  D. Contact details and social links → lib/site.ts (used everywhere)

  E. Photographs → public/images/

The private client page (/hello) lives in app/preview/team/page.tsx.

================================================================================
3. WHERE THINGS ARE
================================================================================

app/
  page.tsx              Homepage, in the order of the design
  stories/, films/, journal/, about/, contact/

  api/contact/route.ts  Sends enquiries by email (Resend)

                        StoriesShowcase, Cinema, Craft, JournalNotes, Inquire

  StoryBoard            Story filters and magazine grid
  InquiryForm           The wedding enquiry form
  VideoPlayer           The "screening room" film dialog
  PageIntro, SectionMarker, ClosingInvite, Reveal, RotatingBadge

lib/                    stories.ts, films.ts, journal.ts, site.ts

================================================================================
4. DESIGN SYSTEM (tailwind.config.ts)
================================================================================

Colours
  • paper    #F7F4EF  main background
  • sand     #EFEAE2  alternate sections and cards
  • obsidian #161412  dark sections, headings
  • bronze   #9E7B56  labels, italics, buttons (gold #C9A96E on dark)
  • char     #2B2420  body text; muted #6E675F for small print

Type (self-hosted via next/font)
  • Display: Cormorant Garamond, with lining figures
  • Body and labels: Plus Jakarta Sans
  • The /hello page keeps Inter for its body text

================================================================================
5. CONTACT FORM
================================================================================

The form posts to /api/contact, which emails helloculttales@gmail.com
through Resend. Set RESEND_API_KEY as a secret on the Cloudflare Worker.
Without it (for example on your computer), enquiries are printed in the
terminal instead of emailed.

================================================================================
6. DEPLOYING
================================================================================

The site deploys to Cloudflare Workers. Setup, domains, media and secrets
are in docs/CLOUDFLARE.md. Pushing to GitHub starts a Cloudflare build.
